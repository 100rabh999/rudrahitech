# Rudra Hitech - Static Site

This is a modernized, responsive static website for Rudra Hitech Pvt. Ltd.

Quick start:

1. Install `http-server` or use `npx`:

```bash
npm run start
```

2. Open http://localhost:3000 in your browser.

Notes:
- Site uses Tailwind CDN and Swiper for the hero carousel.
- Place your logo at `images/logos.png`.
- Edit `index.html` for content changes.
